# Issue 0038: 店舗の通しテストでハンドが一度も始まらなかった（`n` を言わない運用・勝者が決まらない・仮名の金額）

## Date

2026-09-25

## Status

Fixed（ADR-0062。店舗での再確認は未）

## Severity / Priority

- Severity: High（ハンドが始まらないと、聞き取ったアクションがすべて保留され記録が 1 件も残らない）
- Priority: P0

## Area

integration（`integration/engine.py`）/ audio（`audio/recognizer.py`）/ CLI

## Expected Behavior

ディーラーは席番号も `n` /「ハンド開始」も言わない。手札を配ったらハンドが始まり、読み上げたアクションが記録され、
勝者が決まる。

## Actual Behavior

店舗 PC の `python main.py --cli`（席 5・6・8、音声 + RFID）:

```
[聞き取り] 「レイズ ゴール」→ raise
  [未適用] raise (no_active_hand)  ← 状態は変わっていません
[聞き取り] 「コール」→ call
  [未適用] call (no_active_hand)
[聞き取り] 「ベット6」→ bet 6          [未適用] …
[聞き取り] 「ベトナナ」→ アクションとして読めず
[聞き取り] 「レイズ23」「オールイン」「フォールド」→ [未適用] …
[聞き取り] 「ハンド終了」→ アクションとして読めず
```

雑談（「よいしょ」「ちょっと失礼。」「ここ6番に置いてもらっていいですか、そこ。」）はアクションにならなかった（正常）。

## Reproduction

1. `--cli` を起動し、`n` を打たずに手札を配る。
2. アクションを読み上げる。

## Root Cause

1. ハンドは `n` /「ハンド開始」でしか始まらなかった。オーナーの運用ではどちらも言わない。
2. 席番号を言わない運用では「ウィナー」だけでは勝者の席が分からない。ショーダウンでの見せずのマックも扱えなかった。
3. 「ベト」「ゴール」が語彙に無かった。Whisper が金額を仮名で書き起こすと（「ナナ」）読めなかった。

## Fix

ADR-0062:

- 手札が 2 席以上に配られたら新しいハンドを始める。
- 勝者: ほかが全員フォールドしたら残った人。ショーダウンの「フォールド」はアウトオブポジションから順のマック
  （見せずにマックした人は手札が強くても負け）。誰もマックしなければ「ハンド終了」か次の配布で手札とボードから判定する
  （side pot も）。
- 「ベト」= bet、「ゴール」= call、「ハンド終了」、語の直後の仮名の数。
