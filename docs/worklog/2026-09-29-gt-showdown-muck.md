# 2026-09-29 真のアクション入力: ショーダウンで見せずに降りた人を入れられるように

## Goal

オーナーの報告（スクリーンショット付き）: 真のアクション入力の画面で、リバーのアウトオブポジションの
フォールドが入らない。ターン 席5 ベット 1800 / 席4 コール → リバー 席4 チェック / 席5 オールイン 6400 /
席4 コール 6400 → 席4 フォールド（見せずに降りた）が赤く「ベッティングは終わっています（この行は入りません）」。

## 原因

`replay_legal` は pokerkit で行を流し、手番（`actor_seat`）が無くなった（ベッティングが終わった）あとの行を
すべて拒んでいた。ショーダウンで手札を見せずに降りる（マック）のは、ベッティングのあとの出来事。ライブの記録は
これを street=showdown の fold として残す（ADR-0062。「フォールド」= 見せずにマック）ので、真のアクションも
同じ形で入れられないと、そのハンドの行が合わなくなる。
