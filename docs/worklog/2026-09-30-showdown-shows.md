# 2026-09-30 ショーダウン: 役名 = 見せた・見せたあとのマック・8 秒で手札判定

## Goal

オーナーの指示（2026-09-30, 3 通）:

1. 「ショーダウンすべきタイミングで、マックする者は素早くマックしてディーラーがフォールドを宣言するので、次の
   ハンドまで判定を待つ必要はない」
2. 「アウトオブポジションがハンドショウするのに対して、ディーラーは役名を宣言します。この宣言ののち、レアケース
   ですがインポジションが勝っているハンドをマックすることもあり得るので、役名の宣言はハンドショウとして扱って
   ください」
3. 「ハンドショウの際にはリーダーからハンドが外れるため、この宣言は必ず行わないと誰がフォールドしたかわからなく
   なるので、運用でカバーして役名の宣言は必ず行うようにしたい」

これまで（ADR-0062 + 9/26）: 役名 = 勝った手の名前でハンドの終わり。ショーダウンは「フォールド」（アウトオブ
ポジションから順のマック）・「ハンド終了」・次の配布で決め、一定時間での判定は「ディーラーの宣言が遅れると誤る」
として採らなかった。

## Changed files

- `integration/engine.py`:
  - `SHOWDOWN_MUCK_SEC = 8.0`。`_showdown_at`（ショーダウンの最後の出来事 = ベッティングの終わり・役名・マックを
    話した時刻）と `_showdown_shown`（見せた席 → 役名）。ハンドごとに捨て、チェックポイントにも入れる。
  - `_showdown_show`: ショーダウンの役名 = 次に見せる人（`_showdown_turn` = まだ見せても降りてもいない席、
    アウトオブポジションから）。手札で役名に合う席が見せていない中に 1 つだけあればその席（`_seat_with_hand`）。
    全員見せたら `_finish_by_rules`。
  - `_apply_showdown_muck`: 席が言われなければ、まだ見せていない先頭の席のマック。マックのあと、残りが全員
    見せていれば手札で決める。
  - `_check_showdown_timeout`（live の run() と world replay の空き時間）: 期限 = 最後の出来事 + 8 秒（リバーの札が
    あとならその札 + 8 秒）、その時刻までに話し始めた発話が無くなってから `showdown_end` を記録して反映 →
    `_end_showdown` で手札の判定。
  - `_finish_showdown`: 見せた席ごとに役名と判定を突き合わせる（`_check_shown_names`: 違えば要確認。役名が全員に
    あって役名だけの勝者が違えばその席 = `announced`）。札が読めていないときは役名と読めた手札から
    （`_finish_by_announcement`、役名だけで一番強い席が 1 つのとき）。`showdown` の各席に `announced`。
    `announced_hand` は勝った人に言った役名。確定後の役名は、見せた手のどれとも違えば知らせる。
- `core/showdown.py`: `HAND_NAME_RANK`・`best_by_names`（役名どうしの比較。同じ役が一番上に 2 つなら決めない）。
- `audio/recorder.py`: CLI の表示「見せた（ツーペア）」。`main.py`: 起動時の説明。
- schema: `reconstruction_event` 0.12（kind `showdown_end`）、`hand` 1.7（`showdown[].announced`）。
- `tools/measure_capture_accuracy.py`: 全部正しいハンドはショーダウンのマックの行を比べない（入力で任意）。
- tests: `test_hand_name.py` の TestShowdown を新しい決め方で書き直し（3 人: 順に見せる / 見せたあとの 2 人の
  マック / 8 秒で判定 / 役名も無ければ 8 秒で判定 / 期限前の発話を待つ / 手札で役名の席を決める / 役名と手札の
  食い違い / 役名で勝者 / 読めない席 / 役名がベッティングを閉じる / 確定後の役名 / replay）+ TestHeadsUp
  （インポジションが勝っている手をマック / 両方見せる / 見せる前のフォールド）。`test_rfid_folds.py` の
  店舗セッション 2 件と `test_silent_runs.py` の 1 件は、次の配布ではなく 8 秒で決まる形に。

## Expected vs implemented

- 期待どおり。役名が見せた人を表すので、見せたあとの「フォールド」をインポジションに付けられる（役名が無いと
  アウトオブポジションに付く = 役名は必ず言う運用が前提）。
- 見せた順が「最後のアグレッサーから」の卓（リバーでインポジションがベットしてコールされた）でも、役名がその手札
  にだけ合えば見せた席が分かる。同じ役が 2 人にあるときは順番（アウトオブポジションから）になる。
