# 2026-09-30 推定器 v0（影で回す）とシミュレーション — テスト方針 週 1 の開発分の残り

## Goal

テスト方針の週 1（`docs/worklog/2026-09-29-test-strategy.md`）の開発分の残り: シミュレーションと推定器 v0
（ADR-0056 追記 1 の S3、影で回す = 記録も画面も変えない）。オーナーの指示「1週目に進んでください」。

## 形（ADR-0056 追記 1 の 1. どおり）

- 別の実装を作らず、**ライブと同じエンジンを決定的な再生器**にする（`tools/eval_store.py` の `reparse_events` +
  `replay_session`）。
- **選択点** = 発話ごとの読み:
  - Whisper の書き起こしをいまの読み取りで読んだもの。読めればこれが既定。
  - 第 2 の耳の候補（閉じた語彙。候補の確からしさ − 自由に聞いた文の確からしさ が `ear_min_diff` 以上のもの、上から 3 つ）。
  - 雑談・言い直しとして捨てる。
  - 既定（選択肢の 0 番）は、いまの読み直しと同じ規則で選ぶ: Whisper → 第 2 の耳のライブの規則 → 捨てる。
  - ハンドの区切り・勝者の宣言などの制御は選択肢にしない。こうするとハンドどうしが独立に保たれる。
- **探し方**: 1 つの選択点を変えた候補を全部採点し、いちばん良くなる変更を採る（山登り、最大 4 回）。
  - ハンドは記録の持ち点（`hand_stacks`）から始まるので互いに独立。1 回の再生で全部のハンドの候補を同時に採点する。
  - 持ち点の分からないハンド（記録に無い）は選ばない。
  - 発話はハンドの始まりから「終わり + 20 秒」（次の配布まで）に入ったものをそのハンドの選択点にする。
- **採点** = 読みの確からしさの和 + ハンドとしての筋の通らなさの罰（`PARAMS`、v0 の手置き）。
  - 読み:
    - 音の近さで読んだ・額があいまい: −1
    - 第 2 の耳のライブの規則: −0.5
    - 候補を使う: −2 + 0.4 ×（確からしさの差）
    - 読めた発話を捨てる: −4。15 文字以下の短い発話なら −7。
    - 定型の幻聴の下で第 2 の耳が何かを聞いた発話を捨てる: −4（音はあった）
  - 筋:
    - 補ったチェック・コール: −1.5
    - 補ったフォールド: −2
    - 反映できなかった発話: −3
    - 額を寄せた・額の無いベット: −2
    - 額を BB に丸めた: −0.5
    - 言われたアクションの読み替え（チェック → コールなど）: −2.5
    - 勝者を推し量った: −2
    - ボードは先まで配ったのにその前のストリートで全員降りた: −5
    - 一番強い手が見せずに降りた: −2
- **出力** `<sid>.estimate.json`（`--write`）:
  - 付ける項目: `estimator_version`・`params_hash`・`tier`（`session`）。
  - ハンドごとに入れるもの: 選択点と選択肢、いちばん良い列（アクション・勝者・採点の内訳）、次点までの候補（N-best 5）、次点との差、既定から変えたか。

## 採らなかったこと（試して悪かった）

- **ボードに無いストリートのアクションを罰する**: 札が無いのは読めていないだけのことがある。店舗 fded6f75 ハンド 5 では「フロップ、チェック、チェック。」を雑談として捨て、ハンドをプリフロップで終わらせた。
- **最後のハンドの時間帯を無限にする**: 027e4b15 でハンドの 5 分後の雑音に候補「百」を当てはめ、ハンド全体が変わった。
  このハンドは持ち点が記録に無く、前のハンドの再生結果を持ち越して席4 が 500 点しかない状態だった。持ち点の分からないハンドは外した。
- **2 つの耳が食い違ったら第 2 の耳を採る**: zip の開発側の第 2 の耳（全発話）で試すと、店舗 3 セッションで 75 → 73 行に下がった。食い違いは 4 発話で、「オールインフォールド」→「フォールド」、「コール、コール、スリーベン」→「コール」のように、第 2 の耳の語彙（2 語まで）が続けて言ったアクションを縮めたものだった。額の食い違いは無かった。

## 結果

店舗 fixture（真のアクション 18 ハンド・183 行）:

| | 行 | 変わったハンド |
|---|---|---|
| 読み直し（既定） | 159/183（87%） | |
| 推定 | 160/183（87%） | 良くなった 1（7b897671 ハンド 3: 幻聴になったオールインへのコールを第 2 の耳の候補で戻した）・悪くなった 0 |

- 正解が候補（N-best）に入ったのは 13/18。
- 入らなかった 5 つは、どれも v0 の選択点（発話の読み）では届かない:
  - 言われていないアクション: 当時の「同じチェックは言わない」言い方（fded6f75 ハンド 1）、一人テストの言い忘れ（d0f055fb ハンド 3）
  - フロップの札の読み落とし（d0f055fb ハンド 5）
  - 声の無いハンド（d0f055fb ハンド 7）
  - 027e4b15 ハンド 1

シミュレーション（`tools/simulate.py`。台本の声だけのハンドを、誤りを決まった割合で混ぜて読んだことにする。**精度の主張には使わない**）:

| 誤り | 行: 読み直し → 推定 | 全部正しいハンド | 正解が候補に |
|------|------|------|------|
| 既定（聞き違い 6%・幻聴 5%・崩れ 4%・欠落 2%・雑談 15%、4 × 30 ハンド） | 73% → 79% | 53 → 57 / 120（良くなった 14・悪くなった 1） | 72 / 120 |
| 幻聴 10% だけ（3 × 30） | 92% → 98% | 70 → 83 / 90 | 84 |
| 雑談 30% だけ | 79% → 83% | 53 → 58 / 90 | 73 |
| 崩れ 10% だけ | 86% → 88% | 66 → 70 / 90 | 84 |
| 額の聞き違い 12% だけ | 96% → 96% | 67 → 67 / 90 | 84 |
| 欠落 10% だけ | 70% → 69% | 32 → 32 / 90 | 32 |

- 幻聴・雑談・崩れには効く。
- 額の聞き違いは効かない。Whisper が読めた発話は Whisper を採るため。店舗では、Whisper が読めて第 2 の耳と食い違った額の例はまだ無い（上の「採らなかったこと」）。
- 発話の欠落はいちばん重く、選択点が無いので届かない。店舗ではフォールドは札の離脱で決まるので、声だけのシミュレーションより軽いはず。

所要時間: 店舗 fixture 6 セッションで約 20 秒、シミュレーションの 30 ハンドのセッション 1 つで約 15 秒（開発側）。
