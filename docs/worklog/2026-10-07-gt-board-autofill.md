# 2026-10-07 真のアクションの入力画面: ボードを記録から自動で入れる

## Goal

オーナーの依頼（10/07）:「真のアクション入力UIですが、ボードは自動で入力するようにしてください。」

## Expected vs implemented

- 前: ハンドを開いた時点の記録のボードを入れる（進行中のハンドは開いた時点の枚数のまま。ターン・リバーは手で選ぶか、
  開き直す）。保存した真のアクションがあれば、入れた最後の札より後ろだけ記録で補う（`boardWithRecord`）。
- 今（`tools/ground_truth_ui.py` のページ）:
  - 開いたときに、手で入れていない位置は記録（RFID）の札にする（`followRecordBoard`）。保存した真のアクションの札は
    手で入れたものとして変えない。
  - 進行中のハンドは 3 秒ごとに記録を読み直し（`pollBoard`）、手で選んでいない位置に記録の札を入れる（ターン・リバー
    も自動で入る。配り直しで記録の札が変われば合わせる）。ハンドが終わったら読み直しを止める。
  - 手で札を選んだ位置（`S.boardTouched`）は記録で上書きしない。ほかの位置や手札で使っている札は入れない。
  - 入れた札が変われば手番の確認（ショーダウンの勝者の判定）を取り直す。開いただけで自動で入った札は「保存して
    いない変更」にしない。
  - 進行中の案内の文:「ボードの札は開いた時点のもの」→「ボードの札は記録から自動で入ります。手で選んだ札はそのまま」。

## Test results

- `tests/test_tools_ground_truth_ui.py`（+1: ページに自動入力の処理がある）73 passed。
- ブラウザ（Chromium, 手元の確認スクリプト）: 進行中のハンドをフロップで開く → 記録にターンの札が入ると 3 秒ほどで
  入力画面のボードにも入る / 手でリバーに別の札を選ぶと、記録のリバーが入っても変わらない / ハンドが終わると
  読み直しが止まる / ページのエラーなし。

## Remaining gaps

- ボードの一致（`board_match`）は、ボードを手で直さない限り記録と同じになる（RFID のボードの読みは正確なので、
  オーナーの依頼どおり手間を省く方を取った）。
