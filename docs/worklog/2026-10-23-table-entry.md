## 入れたもの

- `tools/table_entry.py`（真のアクション入力のサーバーが `/table` と `/api/table/...` で出す）:
  - `current_hand_id`: 進行中のハンド、無ければ次のハンド（まだ配っていない）。
  - `table_hand`: 入れるハンドの土台。まだ配っていないハンドは前のハンドから見込む（`skeleton_after`: 持ち点が残る席・前の
    ボタンの次の席・ブラインド。前のハンドの真のアクションがあればその収支 = `materialize_truth`、無ければ記録の収支）。
  - `table_legal`: 入れた行を pokerkit で流す（`replay_legal`）。手番より先の席の行の前に、間の席のフォールドを足す（`fill_folds`,
    `auto`）。席ごとの持ち点・出した額・ポジション（`seat_view`）。
  - 保存は入力画面と同じ受け口（`PUT /api/sessions/<sid>/hands/<hid>`, `blind` = 記録を見ずに入れた）。まだ配っていないハンドは
    画面が持っていて（ブラウザにも下書き）、ロガーがハンドを始めたら（2 秒ごとに確かめる）保存する。ロガーだけが入れた席は
    「空席」で出す（押せば戻せる）。何も入れていないハンドは保存しない。
- 画面: 卓の形（ディーラーを上、席 1 をディーラーの左 = 画面の右上から時計回り）。席ごとに F / チェック・コール / ベット・レイズ /
  オールイン、`D`（ボタン）、空席の切り替え、ショーダウンの「勝ち」。テンキー（数字 → Enter、`+` 000、`/`・`*`・`.`・`-`）。
- 入力画面（`/`）の上に「卓の形で入れる (PC) →」のリンク。
