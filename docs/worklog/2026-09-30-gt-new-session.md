# 2026-09-30 ロガーを起動しても真のアクション入力の画面にセッションが出ない

## Goal

オーナー: 「`Start-Process C:\PokerHandLogger\start_logger.cmd` をしたときに、真のアクション UI にセッションが
表示されない」。

## 原因（2 つ）

1. **ハンドの記録ファイルが最初のハンドが終わるまで作られない**。画面（`tools/ground_truth_ui.py:list_sessions`）は
   `logs/*.json`（ハンドの記録）を一覧にする。`JsonWriter` はハンドが終わったときにだけ書いていたので、起動直後や
   1 ハンド目の途中のセッションは一覧に無い。
2. **画面がセッションの一覧を読み直さない**。5 秒ごとの読み直しは選んでいるセッションのハンドの一覧だけで、
   セッションの一覧（ロールダウン）は画面を開いたときと「↻ 読み直す」のときしか読んでいなかった。画面を開いたあとに
   始めたセッションは、ハンドが終わっても出ない。
   - ヘッドレスの Chromium で確かめた: 前の画面は、開いたあとに作ったセッションを 6 秒待っても出さない。

台本のハンド（`start_script.cmd`）では気づかなかった: 画面の台本のページは台本のファイルからセッションを探すうえ、
台本のハンドはすぐに終わる。

## Changed files

- `output/json_writer.py`: `JsonWriter.ensure_created()` = ファイルが無ければハンド 0 のまま作る（あれば何もしない）。
- `main.py`: CLI（`run_cli`）と GUI（`run_gui`）がセッションを始めた時点で `ensure_created()`。記録の再生
  （`integration/replay.py`）とテストは従来どおり（ハンドが終わるまで作らない）。
- `tools/ground_truth_ui.py`（画面）:
  - 5 秒ごとの読み直しでセッションの一覧も読む。
  - `S.follow`: いちばん新しいセッションを見ていれば、新しいセッションが始まったらそちらへ移る。ロールダウンで前の
    セッションを選んだら移らない（一覧には出る）。選んでいたセッションが消えたらいちばん新しいセッションへ。
  - 文字の欄・ロールダウンを触っている間は読み直さない（前の直しのまま）。
- `tests/test_tools_ground_truth_ui.py`: `TestNewLoggerSession`（4）。読み直しの確かめの文字列を新しい形に。

## 確かめたこと

- ブラウザ（ヘッドレス Chromium）: 画面を開いたあとにロガーのセッションを作る → 6 秒以内にロールダウンに出て選ばれ、
  「このセッションにはまだハンドがありません」。前のセッションを選んだあとに別のセッションを作る → 選んだまま、
  一覧には新しいセッションが出る。
- 空のセッションの記録（`hands: []`）を読む側: `tools/eval_store.py`（ハンドが無ければ設定を作らない）・
  `tools/test_script.py`（最後のハンドは無し）・画面の一覧（ハンド 0）はどれも扱える。
