# 2026-09-27 ログを 1 つにまとめて送る（レビュー用）

## Goal

オーナーの質問「ログをどのようにアップロードすれば効率が良いか（レビューしてもらうため）」への対応。これまでは
店舗 PC から `logs\` の 5 ファイル（ハンドの記録・events・transcripts・卓状態・pokerapp.log 全体）を 1 つずつ
チャットに添付していた。pokerapp.log は日をまたいで追記され続ける（前回は 2 日分 2519 行）。

## Changed files

- `tools/pack_logs.py`（新規）: `logs/` のファイルをセッション ID（ファイル名の最初の "." まで）でまとめ、直近 12 時間に
  更新したセッション（無ければいちばん新しい 1 つ）を zip にする。pokerapp.log はセッションの時間帯
  （起動 = 「Created session」の行 / 時刻入りの ID / events・transcripts の最初の時刻 − 60 秒 〜 最後に書いた時刻 + 60 秒）の
  行だけ（時刻の無い traceback の続きの行も含む）。発話の音声は合計 25 MB まで自動で入れる。config.json は
  token / secret / password / api_key のキーを伏せる。`manifest.json` に入れたもの・ハンド数・切り出した時間帯・
  インストールしたコードの指紋（主要 6 ファイルの sha256、改行は LF に揃える = 手元の git 履歴と突き合わせる）。
  出力はデスクトップ（OneDrive へ移されていても `SHGetFolderPathW`）、できたらエクスプローラで選んだ状態で開く。
  `--text` は zip を添付できないときのテキスト 1 ファイル（音声なし）。
- `pack_logs.cmd`（新規, ASCII/CRLF, `%*` でオプションを渡す）/ `installer/install.ps1` のショートカット
  「ログをまとめる (送付用)」/ `tests/test_installer.py` / `docs/installation.md`。
- `tests/test_tools_pack_logs.py`（新規 12）/ `docs/usage.md`（「ログを送る」節）/ `CHANGELOG.md`。
