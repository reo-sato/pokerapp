# 2026-10-24 推定器 v1 のオラクルの採点（台帳 B の ①）

## 目的

台帳 `docs/plan-board.md` の B（推定器 v2）の段取り「① 任意の列の採点 → ② 値を数える → ③ 探索 → ④ 較正」の ①。オーナーは
範囲を **v1 のオラクルだけ**（v2 の採点は F が値を数えてから）と決めた（10/24）。改善案
`docs/worklog/2026-10-23-estimator-improvement-plan.md` §4.1-2 の「オラクルの採点」と同じもの。

物差しは誤りを「正解が候補に無い / 点で負けた」としか分けず、前者には (i) いまの直しでは真を表せない・(ii) 表せるが探し
きれない・(iii) 表せるが点が低くてビームから落ちた、が混ざっていた。これを分け、点で負けたハンドは**どの項で負けたか**を出す。
推定器の値・規則は変えない。

## 変えたファイル

- 新規 `tools/oracle_estimator.py`: 誤ったハンドごとに、推定器と同じ直しの候補（`candidate_edits` = いまの直しの語彙）で
  **真に近い順**（正しい行 − 正しくない・余計な・足りない行 − 勝者の不一致、同じなら点）に探す（幅 8・深さ 6・1 番以外は
  1 手で真に近づいた 24 の直し）。真に届いたら記録を変えずに点を上げる直し（説明の直し）を足してからオラクルとし、1 番と比べる。
  項は群（読み・捨てた語・余計な語・言われない・言われた・取り違え・手の事前・持ち上げ・札の離脱・ボタン・札の時刻・宣言・
  終わり方）に分けて差を出す。表せないハンドは、いちばん真に近い候補との最初に違う行と、**真のベット / レイズの額を賭けとして
  読める発話が窓に 1 つも無いか**（どの読みの選択肢・音で読んだ額の候補にも無い = 入力に情報が無い）を出す。`--dump`・
  `--hands`・`logs`（店舗の zip）・`--workers`。推定器からは import しない（内容の指紋に入らない）。
- `tools/bench_hands.py`: `ScoredHand` / `scored_hands`（物差しと同じハンドの選び方）を `tools/llm_candidates.py` から移した。
- 新規 `tests/test_oracle_estimator.py`: 項の群（推定器が書くラベルが「その他」に落ちない）・真との近さ・最初に違う行・
  推定器が道具を import しない、遅い組で 027e4b15#1 が「点で負けた」・負けた群は「言われない」。
