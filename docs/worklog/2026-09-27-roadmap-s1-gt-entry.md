# 2026-09-27 ロードマップ S1 — 真のアクション入力の手間を減らす

## Goal

ADR-0056 追記 1 の S1。真のアクションを 40〜50 ハンド（うち 2 割はブラインド）集めるために、入力画面
（`tools/ground_truth_ui.py`）の手間を減らし、入れた真のアクションの質（記録に引きずられていないか・自信の無い行）を
測れるようにする。オーナーの「進めてください」を受けて実装。

## Changed files

- `tools/ground_truth_ui.py`
  - サーバー: `hand_timeline`（`<sid>.transcripts.jsonl` の発話 = 文・自信・どう読んだか・認識の遅れ・音声ファイル、
    `<sid>.events.jsonl` のボードの札・札の離脱 / 通過 / 戻り を、配布からの秒数で。範囲は配布の 10 秒前から次の
    ハンドの配布まで）/ `GET /api/sessions/<sid>/audio/<ファイル>`（`logs/audio/<sid>/` の WAV。Range で 206 =
    iPad の Safari が少しずつ取りに来る）/ `is_blind`（`sha1(sid:hand_id)` で 5 ハンドに 1 つ。`--blind-every`、0 で
    なし。真のアクションを入れたあとはブラインドにしない）/ 「記録どおり」は要確認の行（と、ハンド全体が要確認なら
    `confirmed_hand`）をすべて `confirmed_rows` で ✓ していれば通す / `unsure`（行）・`blind`・`entry_sec` を残す /
    一覧の集計に `blind` と `entry_sec_avg`。
  - 画面: 左の列に「発話と札の流れ」（▶ で音声）。記録の表の先頭に ✓（要確認の行だけ）。ブラインドでは記録を隠し
    （書き起こしの「どう読んだか」も隠す）、アクションと勝者を空から。「記録を見る」で解除。行ごとの ?（自信なし）。
    入力にかかった時間（開いてから保存まで）を送る。一覧に平均の入力時間とブラインドの印。
- `tools/eval_store.py`: ブラインドのハンドとそれ以外の一致率・自信なしの行・入力時間の平均。

## Expected vs implemented

- 期待（Fable 5.1 の案 + ロードマップ）: 音声再生・タイムライン・行 ✓・ブラインド（2 割）・行ごとの出所、入力時間。
