# 2026-10-03 宣言の声と雑談の声を数値で見分けられるか

## Goal

オーナー:「雑談をする発声と、アクションを宣言する発声は、発声者の意図としては切り替えというか、別な声の使い方を
していて、プレイヤーのそれを聞き分けていると思うのですが、これらを定量的に区別することはできませんか？」

承認された計画（数字を見る前に判定の基準を固定）:

- **段 0**: 声で完全に分かったら推定の結果が変わるか（変わらなければ推定器への組み込みは検討しない）。
- **段 1**: 1 人 n 役のセッションで、宣言（D）と雑談（C）の声の高さと大きさを**同じセッションの中で**比べる。判定 H1 =
  指数 z(高さ) + z(大きさ) の AUC ≥ 0.70 かつ 95% 区間の下限 ≥ 0.60、長さをそろえた組で ≥ 0.65、進行の言葉（A）対 雑談で
  ≥ 0.65。
- **段 2**（段 0 で効き目があったときだけ）: 推定器に使えるか。

途中のオーナーの指摘（同日）:「現状のテスト設計だと、先ほどの最後の発話のように、雑談と宣言が一体化してある音声ファイル
は見分けられないですよね。」→ その通り（1 ファイル = 1 単位で測っていた。しかも「…、フォールド。」のような文は読み取りが
会話の中の語として捨てるので雑談の側に入っていた）。直し: 賭けの言葉が 1 つでもあるファイルは雑談に数えない / 文字の順で
宣言が最後か最初か分かるものはファイルの中を声の切れ目で区切り、宣言の区切りと同じファイルの雑談の区切りを比べる（判定:
ファイルの中の AUC ≥ 0.70・下限 ≥ 0.55・15 ファイル以上。データを見る前にオーナーに伝えた）。

## 段 1: 結果（`TZ=Asia/Tokyo`、2 回走らせて同じ数字）

1 人 n 役 = 09-27・09-29 の店舗の記録と bb4b1b89（14 セッション）。参考 = 10-01 夜の 4 席の 5 セッション + 1 人かどうか
記録に無い 322f4a78・fa8392cf・e2a719de（8 セッション）。

| | 1 人 n 役（判定） | 参考（プレイヤーあり・不明） |
|---|---|---|
| 発話（宣言・進行の言葉・雑談） | 176・36・107 | 71・19・45 |
| **主の指数の AUC**（同じセッションの中） | **0.69**（95% 0.61〜0.76・並べ替え p < 0.001・1 つ外して 0.59〜0.71） | 0.67（0.55〜0.77） |
| 長さをそろえた組（1.5 倍以内） | 0.65（697 組） | 0.62 |
| 進行の言葉 対 雑談 | 0.64（346 組） | 0.57 |
| 差（組の差の中央値） | 高さ +1.4 半音・大きさ +3.5 dB | 高さ −0.3 半音・大きさ +3.8 dB |
| 大きさだけ / 高さだけ（参考・Holm） | 0.72（p 0.006）/ 0.58（p 0.27） | 0.76 / 0.48 |
| 長さだけ → 長さ + 高さ + 大きさ（1 つ外すロジスティック） | 0.69 → 0.75 | 0.42 → 0.79 |
| 真のアクションと対応した宣言だけ（確かめ） | 0.73 | 0.64 |

- **判定 H1（事前に決めた分け方 = 1 版）: 基準に届かない**（AUC 0.69 < 0.70）。ただし差は偶然ではない（区間が 0.5 から離れている・並べ替え p < 0.001）。
  差はおもに**大きさ**（宣言の方が 3.5 dB 大きい = 卓全体に届ける声）。**高さ**はセッションによって向きが違う（d0f055fb・
  9d1d8536 は宣言が高く、fded6f75 は雑談の方が高い）。長さをそろえても・言葉の違う進行の言葉でも 0.64〜0.65 残る =
  言葉と長さだけの違いではない。プレイヤーが聞き分けるのは、声の大きさに加えて言葉・間・手番・文脈を使っているからと
  考えられる（声だけでは 10 組に 7 組ほど）。
- 声の高さの取り方の確かめ: セッションごとの中央値は 115〜195 Hz（話し声の範囲）、話している枠のうち高さが取れた割合は
  0.3〜0.9。
- **雑談と宣言が 1 つのファイル（オーナーの指摘）**: 文字の順で宣言の位置が分かり、声の切れ目で区切れたのは 1 人 n 役で
  **2 ファイルだけ**（「こんなの入るの、いきなり? コール」「6番 レイズ ボタンを動かしてないよね 4番じゃないの」）→ **数が
  足りず判定できない**。どちらも雑談の区切りの方が大きかった（驚き・指摘の声）。読めた文字で混ざったと分かる発話は
  少なく、オーナーが挙げた例（聞いた 51 の 49 番）のように決まり文句になった発話は文字が無いので位置が分からない。

### 数字を見たあとに直したこと（開示）

- 1 回目の集計（`run1`）の「雑談と宣言が 1 つのファイル」に、崩れて書き起こされた宣言（「チェック アウンド」=
  チェックアラウンド、「コール、チュック。」）が入っていた（片仮名の残りを雑談と数えていた）。雑談の部分は「ひらがな・
  漢字が 3 文字以上」に直した（崩れた宣言は「混ざった」として数えない）。D・A・C の分け方は 1 回目と同じ（確かめた）。
- この直しで、セッションの z の物差しに使う発話の集まりが少し変わり、主の数字が小数 2 桁目で動いた: 1 回目は AUC 0.69
  （95% 0.62〜0.76）・進行の言葉 対 雑談 0.65、直したあとは 0.69（0.61〜0.76）・0.64。判定（基準に届かない）は同じ。
- 計画では「`is_question` の質問は雑談から除く」としていた。`is_question` は「〜ですね」で終わる文も質問とみなすので、
  雑談の数が減った（1 人 n 役で 31）。計画どおり除いた。

### 分け方の 2 版（数字を見たあとに直した。参考・判定には使わない）

「いちばん宣言らしい雑談」を聞き比べる例を並べたところ、雑談の側に配る人の進行の声（「アクションです。」×4・
「ターンです。」「リバーです。」「シート3です。」「ボタンは6席」）と崩れた宣言らしい片仮名の語（「ピアクター」「フローク」
「ペットボックス」）・相づち（「はい」）が入っていた。2 版: 卓の言葉とつなぎの言葉だけの発話は進行の言葉（A）、雑談（C）は
ひらがな・漢字が 3 文字以上の文だけ。`--labels 1` で 1 版（上の主の数字）がそのまま出ることを確かめた（`--labels 2` が既定）。

| | 1 人 n 役 | 参考 |
|---|---|---|
| 発話（宣言・進行の言葉・雑談） | 176・44・82 | 71・19・36 |
| 主の指数の AUC | 0.72（95% 0.64〜0.79・p < 0.001・1 つ外して 0.60〜0.76） | 0.63（0.51〜0.75） |
| 長さをそろえた組 | 0.69（517 組） | 0.56 |
| 進行の言葉 対 雑談 | **0.57**（405 組） | 0.54 |
| 差 | 高さ +1.6 半音・大きさ +3.7 dB | 高さ −0.1 半音・大きさ +3.5 dB |

- 雑談をきれいにすると宣言との差は少し大きくなる（0.69 → 0.72）。一方、進行の声（「アクションです。」など）は雑談と
  ほとんど同じ声（0.57）= **大きな声になるのはベッティングの宣言で、進行の決まり文句は普段の声**。
- 2 版は数字を見たあとの直しなので、確かめるなら次の 1 人 n 役のセッションで（2 版・同じ基準）。
