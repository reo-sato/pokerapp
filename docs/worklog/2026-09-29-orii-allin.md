# 2026-09-29 「オーリー」= オールイン、短い語のあとの「です」

## Goal

オーナー: 「オーリーと聞こえた発話がオールインと読めずアクションにならない問題も残っています」。

## 原因

- 「オーリー」: 辞書に無く、音の近さ（`audio/phonetic.py`）では相づちの「オーライ」（距離 0.2）が
  「オーリン」（0.25）・「オールイン」（0.26）より近い。「オーライ」はオールインと取り違えないための
  「アクションでない語」なので、いちばん近いときは読まない（誤ってオールインにすると被害が大きい）。
- あわせて、辞書の短い語（`_BOUNDARY_KEYWORDS`）は前後が区切りのときだけ読む規則で、「です」も片仮名に寄せた
  あとの「デス」= 仮名の続きとみなして拒んでいた（「オーリンです」「ソーダウンです」「ホールドです」）。

## Changed files

- `core/constants.py`: `"オーリー": "allin"`（店舗 2026-09-25・09-29 の実測）。
- `audio/recognizer.py`: `_BOUNDARY_KEYWORDS` に「オーリー」。`_BOUNDARY_SUFFIX` = 「デス / デース / デシタ」（＋ネ / ヨ）
  のあとが片仮名でなければ区切り（「ホールドデスク」は拒む）。音の近さの `_isolated` は変えない（音の近さで読む
  語は推測なので、これまでどおり厳しく）。
- テスト: `tests/test_play_gate.py`（短い語の区切り +8）/ `tests/test_phonetic.py`（「ホールドです」は辞書の語として
  フォールドになったので、音の近さの拒む例から外した）。

## 確かめたこと

- 店舗の書き起こし全体（2 つの zip）で、読み方が変わる発話は無い。
- 「オーリーですね」は確認の問いかけ（「〜ですね」）として読まない（既存の決まり = 「コールですね」と同じ）。
- 全体 1857 passed / 6 skipped、ruff clean。
