# Worklog: 店舗 PC なしで、真のアクションの入力画面と同じ形で見直すページ

## Date

2026-10-08

## Scope / Task

オーナー:「今店舗 PC を触れないので、真のアクション入力 UI と同じ形でレビューできるようにしてください」。選んでもらった
進め方: 対象は確認待ちの 2 ハンド（e82f5005 ハンド 15・d0f055fb ハンド 8）、音声は発話ごとの WAV をチャットで送る（ページには
載せない = 店舗の音声は公開しない）、直した真のアクションはページで保存して開発側が読む。

## やったこと

- `tools/review_page.py`（新規）: 開発データ（`tests/fixtures/store/<日付>-<sid>`）のハンドから、ページの材料を作る。記録
  （いまの規則での読み直し = `SessionEstimator.windows()` の直しの無い再生）・推定（推定器の 1 番）・真のアクション・時系列
  （発話の Whisper の文・第 2 の耳の文・オーナーの聞き取りのラベル・読み取ったアクション・ボードの札・席の札の離脱）・問いの文。
  発話には音声の番号を付け、`--audio` で WAV をその番号の名前（`<sid8>_h<ハンド>_<番号>_<+秒>.wav`）にコピーする。
  保存された内容の読み戻しは `load_reviews`（入力画面の `validate_gt_hand` で検査）。
- `tools/review_page_template.html`（新規）: 入力画面と同じ暗い配色・部品のページ。左 = 記録・推定・時系列、右 = 真のアクションの
  編集（ボード・手札・見せた・ボタン・行の編集/挿入/削除・?・記録と違う行の印・勝者・メモ・評価から外す）。サーバーが無いので、
  ページの確かめは「降りた席のアクション・ストリートの順・額・同じ札・勝者」だけ（完全な確かめは読み戻しのとき）。保存は
  claude.ai のページの共有データ `reviews/<sid8>_<ハンド>`。
- ページは claude.ai に非公開で出した（店舗の書き起こしを含むのでリポジトリには入れない）。WAV 16 個をチャットで送った。
- 確かめ: ローカルの Chromium で 1280 / 400 幅、エラーなし・横にはみ出さない・行の追加と保存の呼び出し（共有データは仮のもの）。
  公開後に共有データへ 1 件書いて読めることを確かめて消した。`tests/test_review_page.py`。
