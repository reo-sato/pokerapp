## Goal

GUI の手動入力 (席ドロップダウン + action ボタン + amount entry) が
`GameStateManager.apply_action` を直叩きしていたため、`BettingState` が
スキップされて 5 件のポーカールール違反が通っていた。これを音声経路と同等
品質で扱うために、IntegrationThread 経由に揃える。

Issue: [0001-manual-input-poker-rule-violations](../issues/0001-manual-input-poker-rule-violations.md)
Design: [ADR-0001](../adr/0001-route-manual-input-via-integration-thread.md)

### Handler 詳細

`_handle_manual_action_event(event)` の処理順:

1. event.seat / event.action / event.amount を取り出し。
2. `bs.actor_seat` と event.seat を比較 → mismatch なら `needs_review=True`
   フラグを立てる (apply は通す)。
3. event.action == "call" かつ event.amount == 0 のとき:
   - `bs.call_amount_for(seat) > 0` なら amount をそれで上書き (auto-fill)
   - `bs.call_amount_for(seat) == 0` なら action を "check" に置き換える
4. event.action == "bet" かつ `bs.is_opened` なら `needs_review=True`
   (= raise が canonical な状況で bet と入力されている)。
5. `gs.apply_action(seat, action, amount)` で stack / pot を更新。
6. `bs.is_initialized` のとき `bs.update_after_action(seat, action, amount)`
   で BettingState を同期。
7. `ActionRecord` (`source={"manual": True, "needs_review": ...}`) を組み立てて
   `on_action(record)` を発火。

### 意図的な scope-out (= EvidenceLog / BeamEngine に流さない)

manual events は observation ではなく operator の介入なので:
- `EvidenceLogWriter.write_*` は呼ばない
- `self._beam.step_audio` は呼ばない
- `self._track_evidence(...)` は呼ばない

これにより `HandReconstructor` のオフライン再構成は manual events を見ない。
online HandSummary.actions には含まれるので、`_compute_diff` で「online には
manual action があるが offline には無い」差分として出てくる。これは intentional
で、review UI で operator が確認できる。

詳細は ADR-0001 の "Consequences" 参照。

## Mismatches found during testing

実装中に 2 件の test side のバグを発見・修正:

### Mismatch 1: bound method identity comparison が不安定

最初に書いた test で `assert gs.apply_action is gs_apply_action_before` を
使っていたが、bound method の identity は call ごとに変わる場合があるため
unreliable。**Fix**: `pot` / `stack` の値そのものを before/after で比較する
形に書き直し。

### Mismatch 2: `_make_mock_dashboard` の seat 制約

GUI test で seat=3 の `ManualActionEvent` を送ろうとしたが、
`_make_mock_dashboard` は seats=[1, 2] (Alice/Bob) しか setup していなかったので
`ValueError: Unknown seat: 3`。**Fix**: test 内で seat=1 を使う形に修正。

両方とも実装側 (production code) ではなく test 側の問題。production behavior には
影響しない。
