# ADR-0074: ディーラーへの働きかけ（区切って言う手引き・営業のあとの振り返り・ディーラー名の記録）

## Status

Accepted（2026-11-20。オーナー「現状の正答率は 48% だが、実際にはディーラーの発声が不十分である場合が多いので、システムの
正答率はそれなりに高いと思っている。各アクションの復唱の間をなるべく区切るなどの工夫とともに、ディーラーへのインタラクションを
改善したい」。選択: その場で返す画面は作らない・音の合図は使わない・11/19 の聞き分けはオーナーが行う・ディーラー名を残す）

## Context

- 前向きの正解率は 48%（ADR-0056 追記 7）。誤りの約 2/3 は「正解が候補に無い」= 入力の欠け。
- 言った・言っていないを分けた実測は 10/26 の 1 回だけ（旧 Whisper, `tools/listen_missed.py`）。
  - 読めなかったコール・フォールド 76 行のうち 54 行（71%）は言っていて、書き起こしで落ちていた。
  - セッションの後半ほど言わなくなっていた。
  - 今の書き起こし（gpt-transcribe）での割合は分かっていない。
- 発話の区切りは約 0.45 秒の無音、5 秒で途中で切る（`audio/recorder.py`）。1 息の複数のアクションは
  `parse_actions` が分けるが、2 つ目の語が崩れやすく、崩れるとそのあとの人のアクションまでずれる（ADR-0061）。
- `docs/usage.md` は「続けて言っても構いません」と書いていた。紙の手引きは無かった。誰が配っていたかの記録も無かった。
- 11/19 の振り返り（`tools/dealer_report.py`）: 読めたコールは 19〜20 時の 100%・89% から、21〜22 時は 54%・59% に下がった。
  続けて言った発話はアクションを読んだ発話の 25%。

## Decision

1. **その場でディーラーに返す画面・音は作らない**（オーナー）。ディーラーには紙の手引きと、営業のあとの振り返りで返す。
2. **区切って言う**を決まりにする。
   - アクションごとに 1 拍（半秒以上）あける。額は 1 息で言い切る（「2千…500」と切らない）。
   - ディーラー用の紙 1 枚 `docs/dealer-guide.html`（A4, ブラウザで開いて印刷）。`docs/usage.md` も同じ内容に直す。
   - 決まりを変えたら usage.md と手引きを一緒に直す。
3. **ディーラー名を記録する**（席替え・ボタンと同じ通り道, ADR-0059 / ADR-0073 D4）。
   - 卓の設定（PC の設定画面・iPad の「卓を始める」）に任意の「ディーラー」。設定の値は最初の入力 `set_dealer` として積む
     （events.jsonl に残り、replay でも同じ）。
   - 交代は端末の `dealer <名前>` / `dealer -`、制御 `set_dealer`（iPad のハンドのタブ「ディーラー交代」）。
   - ハンドの途中の交代は**次のハンドから**。記録は `HandSummary.dealer`（hand schema `1.13`, additive）。
   - ゲームの状態・推定器は使わない（推定器の内容の指紋は engine・hand_log・control_queue を含むので変わる。値と結果は変わらない）。
4. **営業のあとの振り返り** `tools/dealer_report.py`（ディーラーごと・1 時間ごと）。
   - 真のアクションが無くても: フォールドの声 / フォールド、補ったチェック・コール、額の無いベット・レイズ、
     続けて言った発話、5 秒で切れた発話。
   - 真のアクションがあれば: 配る人が言うアクションのうち読めた割合（種類ごと, `eval_store.listening_stop_metrics`）。
   - `--brief` = ディーラー本人に見せる版（数字 3 つと「次に気をつける 1 つ」。書き起こしの文は出さない = 卓の会話が入るため）。
5. **聞き分けで効き目を分ける**: `tools/listen_missed.py --summary`（読めなかったフォールドの、札が離れた −1〜+6 秒の声の
   有無）と、オーナーが聞いて付ける「言った / 言っていない」。11/19 の自動の数ではほぼすべてに声があった（8 人卓は話し声が
   多い）ので、聞き分けはオーナーの耳で決める。
   - 「言っていない」が多ければ手引きと振り返りが効く。「落ちた」が多ければ書き起こしの側（プロンプト・区切り・読み取りの規則）を直す。

## Consequences

- 次の店舗テストで手引きを渡し、ディーラー名を入れて営業する。振り返りの数字を前回（11/19）と比べ、前向きの 2 つの数字
  （ADR-0056 追記 7）と並べて報告する。
- 画面・音の合図は、紙と振り返りで足りなければあとで考える（卓モニタ `:8790` に聞き取りを出す形が最も小さい）。
- ディーラーごとの数字は本人への振り返りに使うもので、評価・査定には使わない（店の運用で決める）。
