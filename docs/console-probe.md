# マイクの確認: RDP の外で録音できるか（ADR-0073 段階 0）

iPad だけでロガーを起動するには、ロガーが **RDP の外**（PC の再起動のあと自動でサインインした状態 = コンソール）で
録音できなければなりません。いまはいつも RDP の中で起動しているので、ここを確かめたことがありません。

Windows の動き:

- 再起動のあと自動でサインインしたセッションは「コンソール」です（PC につないだ画面 = HDMI のダミー）。
- 同じユーザーで RDP につなぐと、そのセッションがそのまま RDP のセッションになります。マイクの行き先は、接続元の
  音声の設定で変わることがあります。
- RDP を × で閉じると「切断」になり、コンソールには戻りません。

この確認では、記録の道具（`tools/console_probe.py`）をタスクで動かしたまま、次の状態に順に移します。

- RDP でつないでいる
- 切断
- コンソール
- RDP
- コンソールに戻す

道具は 5 秒ごとに「どの状態か・マイクを開けているか・声の大きさ」を記録します。音声そのものは保存しません。

## 準備（RDP でつないで）

1. 店舗 PC を更新する（チャットで渡す更新のコマンド）。
2. **ロガーは閉じておく**（同じマイクを同時に使わないため）。店舗サーバーはそのままで構いません。
3. フォルダ `C:\PokerHandLogger` の **`console_probe.cmd`** をダブルクリックする。
   「マイクの確認を始めました（60 分…）」と出たら Enter で閉じます。

## 確かめる状態（それぞれ 1〜2 分、マイクに向かって話す。数を数えるだけでよい）

| 順 | 状態 | やること |
|---|---|---|
| A | RDP でつないでいる（今の運用） | つないだまま話す |
| B | 切断 | RDP を右上の × で閉じる → 店でマイクに話す |
| C | コンソール | iPad などから RDP でつなぎ直し、スタート → 電源 → **再起動**。自動でサインインするまで 2〜3 分待ち、**RDP でつながずに**話す（サインインのときに記録がもう一度 60 分始まります） |
| D | コンソールから RDP に移った | RDP でつなぐ → 話す |
| E | コンソールに戻した | RDP の中の PowerShell で下のコマンド（管理者の確認が出ます）。RDP が切れたら話す |
| F | 子のプロセス | RDP でつなぎ直し、PowerShell で `schtasks /End /TN PokerConsoleProbe` → 1 分待つ |

E のコマンド（このセッションを、RDP からコンソールに移します。切断ではなく、コンソールで使っている状態に戻る）:

```
Start-Process powershell -Verb RunAs -ArgumentList '-NoProfile -Command tscon.exe (Get-Process -Id $PID).SessionId /dest:console'
```

## 結果を送る

最後に `console_probe.cmd report` をダブルクリックし、出てきたまとめをチャットに貼ってください。

まとめは、状態ごとの区間に 1 行ずつ出ます。例:

```
== 20261119_190012.jsonl
  開始 19:00:12  RDP でつないでいる  （標準入力 なし・標準エラー なし）
  19:00:17〜19:02:02  RDP でつないでいる: マイクを開けている（Wireless Mic Rx）・声あり 9 回・最大 2300
  19:02:07〜19:04:12  切断（RDP を閉じたまま）: マイクを開けている（Wireless Mic Rx）・声なし（最大 12）
  …
  子のプロセス: 本体が止まった 19:31:05 のあとも 19:32:10 まで動いた（本体を止めても子は残る）
```

- 「声なし（最大 12）」は、マイクは開けているのに音が届いていない状態です（無音）。
- 「マイクを開けない（…）」は、開けなかった理由が出ます。
- 「一覧が WDM-KS だけ」は、RDP の音声が接続元に回っている状態です（`docs/troubleshooting.md`）。

記録は `logs\console_probe\` に残ります（音声は入っていません）。終わったらタスクを消してください:
`console_probe.cmd remove`。

## 何を決めるか

- コンソールで声が取れれば、iPad からの起動（ADR-0073）はそのまま進められます。
- 切断（B）で声が取れなければ、RDP を閉じるときは × ではなく E の方法でコンソールに戻す運用にします
  （デスクトップに「RDP を閉じる」のショートカットを用意する、など）。
- 子のプロセスが残るかどうか（F）で、店舗サーバーがロガーを持つ形（子のプロセスか、別のタスクか）を決めます。
